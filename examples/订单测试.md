# 订单功能测试

## 前置条件
- 已登录系统（admin / 123456）
- 商品列表有至少 2 个商品
- 浏览器已打开到订单页面

---

## TC-01: 正常创建订单
| 前置条件 | 操作步骤 | 预期结果 |
|---------|---------|---------|
| 已登录 | 1. 点击「新建订单」 | 弹出新建表单 |
| 库存充足 | 2. 选择商品 A × 2 | 金额自动计算为 商品A单价×2 |
|           | 3. 选择商品 B × 1 | 总金额更新 |
|           | 4. 点击「提交」 | 提示「创建成功」 |
|           | 5. 检查网络请求 `POST /api/order` | 返回 200 |
|           | 6. 检查控制台 | 无 error |

## TC-02: 空订单提交
| 前置条件 | 操作步骤 | 预期结果 |
|---------|---------|---------|
| 已登录 | 1. 点击「新建订单」 | 弹出新建表单 |
| 未选商品 | 2. 不选择任何商品 | 商品列表为空 |
|           | 3. 点击「提交」 | 提示「请至少选择一件商品」 |
|           | 4. 检查网络 | 无 POST 请求发出 |

## TC-03: 取消创建
| 前置条件 | 操作步骤 | 预期结果 |
|---------|---------|---------|
| 已登录 | 1. 点击「新建订单」 | 弹出新建表单 |
|           | 2. 选择商品 A × 1 | 显示已选商品 |
|           | 3. 点击「取消」 | 表单关闭，回到列表页 |
|           | 4. 检查控制台 | 无 error |
