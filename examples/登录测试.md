# 登录测试

## 前置条件
- 已打开登录页面（http://localhost:5173/login）
- 数据库有测试账号：admin / 123456

---

## TC-01: 正常登录
| 前置条件 | 操作步骤 | 预期结果 |
|---------|---------|---------|
| 登录页已打开 | 1. 输入用户名 `admin` | 输入框显示内容 |
| 输入框可用 | 2. 输入密码 `123456` | 密码框显示掩码 |
|           | 3. 点击「登录」按钮 | 跳转首页 |
|           | 4. 检查控制台 | 无 error |
|           | 5. 检查网络请求 `/api/login` | 返回 200 |

## TC-02: 空用户名登录
| 前置条件 | 操作步骤 | 预期结果 |
|---------|---------|---------|
| 登录页已打开 | 1. 密码填 `123456` | 密码框显示内容 |
|           | 2. 用户名留空 | 输入框为空 |
|           | 3. 点击「登录」按钮 | 提示「请输入用户名」 |
|           | 4. 检查控制台 | 无 error |

| 前置条件 | 操作步骤 | 预期结果 |

## TC-04: Tab 键切换聚焦
| 前置条件 | 操作步骤 | 预期结果 |
|---------|---------|---------|
| 登录页已打开 | 1. 按 Tab | 聚焦到用户名输入框 |
|           | 2. 再按 Tab | 聚焦到密码输入框 |
|           | 3. 再按 Tab | 聚焦到登录按钮 |
