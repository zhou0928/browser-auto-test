# 示例测试计划

本目录包含可直接使用的测试计划模板。

## 用法

对你的 AI 助手说：

```
跑一下 examples/登录测试.md
```

AI 会自动读取 Markdown 表格，逐条执行每个 TC，截图留证并输出测试报告。

## 模板列表

| 文件 | 说明 | 用例数 |
|------|------|--------|
| [登录测试.md](登录测试.md) | 登录页功能测试（正常/空用户名/错误密码/Tab 键） | 4 |
| [订单测试.md](订单测试.md) | 订单创建测试（正常创建/空提交/取消） | 3 |

## 自定义

复制任意 `.md` 文件，修改表格内容即可。格式要求：

```markdown
## TC-编号: 用例描述
| 前置条件 | 操作步骤 | 预期结果 |
|---------|---------|---------|
| 条件    | 1. 步骤1 | 结果1    |
|         | 2. 步骤2 | 结果2    |
```

> 每张表格 3 列：**前置条件**、**操作步骤**、**预期结果**。
> 支持多个 TC，AI 会逐个执行。
